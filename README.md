# 📊 Data Science Salary Dashboard

An interactive **Microsoft Excel dashboard** for analyzing salary trends across data science and related job roles.

The project uses a dataset of **32,672 job postings** and provides salary insights based on **job title, country, and employment type**.

## 🚀 Features

* Interactive salary dashboard
* Filter salaries by:

  * Job Title
  * Country
  * Employment Type
* Median salary analysis
* Job title-wise salary comparison
* Country-wise salary analysis
* Employment-type salary comparison
* Dynamic Excel formulas and data validation
* Clean and user-friendly dashboard

## 📁 Dataset

The dataset contains information such as:

* Job Title
* Job Location
* Country
* Company
* Employment Type
* Work-from-home availability
* Salary (Yearly/Hourly)
* Job Posting Date
* Required Skills

## 🛠️ Tools & Excel Features

* Microsoft Excel
* Excel Tables
* Data Validation
* `FILTER()`
* `MEDIAN()`
* `IF()`
* `SEARCH()`
* Dynamic Arrays
* Data Analysis & Visualization

## 📈 Key Analysis

The dashboard allows users to answer questions such as:

* What is the median salary for a particular job role?
* How does salary vary across countries?
* Which employment types offer higher median salaries?
* How does salary differ between data-related job titles?

## 🎯 Objective

The goal of this project is to demonstrate practical skills in **Excel data analysis, dynamic formulas, dashboard development, and business-oriented data interpretation**.

## 📌 Project

**Data Science Salary Dashboard — Excel**

Built to practice and demonstrate real-world data analysis and dashboarding using Microsoft Excel.
